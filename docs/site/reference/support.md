# Support

Before reporting a problem, collect:

```bash
capicove --version
capicove doctor
```

Include the operating system, Python version, installed extras, command or Python
entry point, sanitized input shape, expected behavior, actual result, and relevant
warnings. Remove source media, credentials, private paths, model tokens, and other
sensitive content.

Use GitHub Issues for reproducible bugs and usage questions. Do not report security
vulnerabilities in public issues; follow the private process in the repository's
`SECURITY.md`.
