# Capicove Support

Capicove provides preview capabilities with feature-specific support boundaries.
Experimental features do not carry a production support commitment.

Use the appropriate channel:

- **Reproducible defect:** open a Bug Report issue.
- **New capability or behavior:** open a Feature Request issue.
- **Architecture or public-contract change:** open an RFC issue before coding.
- **Usage or design question:** open a Question issue, or use GitHub Discussions when enabled.
- **Security vulnerability:** follow [SECURITY.md](SECURITY.md), never a public
  issue.
- **Conduct concern:** follow the private process in
  [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

When asking for help, include the Capicove version or commit, operating system,
Python version, installation method, relevant plugin names, a minimal reproduction,
and sanitized output from `capicove doctor`.

Maintainers prioritize security, data integrity, regressions, and work attached to
the current roadmap. A submitted issue does not create a service-level agreement.
