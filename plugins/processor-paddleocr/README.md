# capicove-processor-paddleocr

Optional processor-paddleocr plugin for Capicove 0.1.x.

```bash
python -m pip install "capicove-processor-paddleocr==0.1.0"
```

Install this package together with a compatible Capicove distribution. The plugin
is selected explicitly; installation does not start services or download models.
Runtime prerequisites, configuration and examples are in the
[Capicove capability guide](https://capicove.readthedocs.io/en/latest/getting-started/capabilities/).

Source and issue tracker: [happyBayes/capicove](https://github.com/happyBayes/capicove).
